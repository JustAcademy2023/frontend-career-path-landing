# Frontend Development Career Path: Beginner to Professional Developer

An interactive, single page landing site that maps the frontend developer career path for beginners in Delhi and the NCR. The colour palette comes from the four logos of the frontend world: HTML orange, CSS blue, JavaScript yellow and React cyan.

## What is inside

- A hero with a live typing code window. Switch between HTML, CSS, JavaScript and React and watch the preview change.
- An interactive four stage roadmap with topics and a proof of progress for each stage.
- A skills checklist with a four colour progress bar and a readiness message.
- Course cards and guide cards, all fully clickable.
- Sticky header, responsive layout, keyboard focus styles and reduced motion support.

## Run it locally

Open `index.html` in any browser. No build step, no dependencies. Fonts load from Google Fonts.

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. Go to Settings, then Pages.
3. Under Build and deployment, choose the `main` branch and the root folder.
4. Save. Your site will be live at `https://<your-username>.github.io/frontend-career-path-landing/`.

## Customise

Colours live in the `:root` block at the top of the style section. Roadmap stages and checklist items are plain arrays in the script at the bottom of `index.html`.
